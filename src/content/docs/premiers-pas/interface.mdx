## Les quatre zones à connaître

1. **Le serveur actif**, dans la barre du haut. Cliquez dessus pour changer de serveur.
2. **La barre latérale**, organisée par usage : Général, Modération, Sécurité, Système d’XP, Économie & RPG, Communauté, Staff, Cross-Serveur et Configuration. Tout en bas, hors de ces groupes, se trouvent **Administration** (réservée aux administrateurs de l’instance), [**Facturation**](../../dashboard/configuration/facturation/) et votre profil.
3. **La zone centrale**, qui affiche la page choisie et ses actions.
4. **Votre profil**, en haut à droite, pour relancer le tutoriel, ouvrir vos paramètres ou vous déconnecter.

## La vue d’ensemble

La page d’accueil regroupe les informations dont votre équipe a besoin en un coup d’œil : membres, activité en ligne, fréquentation des salons vocaux, croissance et événements récents.

Le bouton **Modifier la disposition** permet de déplacer, masquer ou redimensionner les blocs. Votre disposition est personnelle : elle ne change pas celle des autres membres du staff.

:::caution[Modifications non enregistrées]
Sur les pages de configuration, une barre apparaît en bas de l’écran dès qu’un réglage change. Cliquez sur **Enregistrer** avant de changer de page. Kotbo vous prévient si vous tentez de quitter avec des changements en attente.
:::

## Navigation rapide

| Raccourci | Action |
| --- | --- |
| <span class="kbd">/</span> | Rechercher dans la barre latérale |
| <span class="kbd">Ctrl</span> + <span class="kbd">K</span> | Rechercher dans la barre latérale (deux fois : palette de commandes) |
| <span class="kbd">Ctrl</span> + <span class="kbd">G</span> | Changer de serveur |
| <span class="kbd">G</span> puis <span class="kbd">D</span>, ou <span class="kbd">Ctrl</span> + <span class="kbd">Shift</span> + <span class="kbd">D</span> | Ouvrir la vue d’ensemble |
| <span class="kbd">G</span> puis <span class="kbd">M</span>, ou <span class="kbd">Ctrl</span> + <span class="kbd">Shift</span> + <span class="kbd">M</span> | Ouvrir les membres |
| <span class="kbd">G</span> puis <span class="kbd">C</span>, ou <span class="kbd">Ctrl</span> + <span class="kbd">Shift</span> + <span class="kbd">C</span> | Ouvrir le Centre de gestion |
| <span class="kbd">G</span> puis <span class="kbd">L</span>, ou <span class="kbd">Ctrl</span> + <span class="kbd">Shift</span> + <span class="kbd">L</span> | Consulter les logs d’activité |
| <span class="kbd">Ctrl</span> + <span class="kbd">Shift</span> + <span class="kbd">N</span> | Afficher tous les raccourcis |

Les raccourcis ne se déclenchent pas lorsque vous écrivez dans un champ ou une zone de texte.

:::tip[La palette de commandes cherche aussi les onglets]
Une page comme **Économie & RPG** ou **Analytics** découpe son contenu en onglets. La palette les connaît : chercher « bestiaire » ou « rétention » vous mène directement au bon onglet, sans passer par la page.

Elle ne propose que ce que votre rôle ouvre : les pages d'un module coupé et celles qui vous sont fermées n'y apparaissent pas, exactement comme dans la barre latérale. Un changement d'accès par rôle est pris en compte sans attendre ni recharger la page.
:::

## Le sélecteur d'emoji

Partout où un réglage demande un emoji - réactions, panneaux de tickets, règlement, boutique, messages d'accueil - le sélecteur propose trois sources :

* **Emojis** : les emojis Unicode standards.
* **Serveur** : les emojis personnalisés de votre serveur, avec le nombre d'emplacements utilisés.
* **Importer** : créer un emoji directement sur le serveur depuis une image (PNG, JPEG, GIF ou WEBP), en lui donnant un nom.

:::note[L'import demande une permission]
*Le bot n'a pas la permission « Gérer les expressions » sur ce serveur, ou vous n'êtes pas administrateur.* L'onglet Serveur affiche *Emojis du serveur indisponibles* quand Kotbo ne peut pas les lire.
:::

## Badges et états de pages

- **Bêta** : la fonction est utilisable, mais peut encore évoluer. Vous pouvez signaler un problème depuis la bannière de la page.
- **WIP** : la fonction n’est pas encore disponible ou nécessite une activation spécifique.
- **Module désactivé** : la page peut disparaître de la navigation jusqu’à l’activation du module.

Continuez avec [l’activation des modules](../modules/).
